# Hoshanot Chabad for REDMI Watch 5

Vela JS Quick App for REDMI Watch 5 (432x514).

Features:
- Chabad hoshanot scans with nikud
- Days 1-6 and Hoshana Rabba
- Manual scrolling
- Automatic scrolling
- Speed selector: 2, 3, 4, 5, 7, 10 seconds per approximate siddur line

GitHub Actions builds the RPK automatically on every push.
